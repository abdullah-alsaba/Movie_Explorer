# MovieExplorer

A React application for browsing, searching, and viewing movie and show details using the TVMaze API.

## Tech stack

- React
- Vite
- JavaScript
- CSS (Tailwind to be added as development continues)

## Scripts

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal to view the app.

```bash
npm run build
npm run preview
```

## Project status

This is the initial MovieExplorer baseline. Core pages, styling, routing, and API features will be added next.
